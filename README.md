# golpobela (গল্পবেলা)

বাংলা ছোটগল্প পড়ার জন্য আধুনিক Dioxus অ্যাপ। Web, Mobile (Android), এবং Desktop (Linux, Windows, macOS)-এর জন্য তৈরি।

## মূল বৈশিষ্ট্যসমূহ (Features)
- 📖 **বাংলা ছোটগল্প রিডার:** চোখের জন্য আরামদায়ক টাইপোগ্রাফি ও থিম।
- ☰ **সাইডবার মেনু ড্রয়ার:** এক ক্লিকে সব গল্পের তালিকা ব্রাউজ ও পড়া।
- 👤 **প্রোফাইল ও অ্যাডমিন প্যানেল:** পড়ার পরিসংখ্যান ও সুরক্ষিত অ্যাডমিন মোড (পাসওয়ার্ড প্রোটেক্টেড)।
- ✍️ **গল্প পরিচালনা:** অ্যাডমিন নতুন গল্প যোগ, পরিবর্তন (Edit) ও ডিলিট করতে পারবেন।
- ↕️ **ড্র্যাগ অ্যান্ড ড্রপ রিয়াররেঞ্জ:** মাউস দিয়ে ড্র্যাগ করে বা মোবাইল বোতাম দিয়ে গল্পের ক্রম পরিবর্তন।
- ☁️ **Firebase Realtime Database:** সব গল্প স্বয়ংক্রিয়ভাবে ক্লাউডে সিঙ্ক হয়; যেকোনো ডিভাইস থেকে একই গল্প পাওয়া যায়।
- 🚀 **মাল্টিপ্ল্যাটফর্ম সিআই/সিডি (GitHub Actions):** কোড পুশ করলেই Web, Android APK এবং Desktop বাইনারি তৈরি হয়।

## চালানো (Development)

ওয়েব প্রিভিউ-এর জন্য:
```sh
dx serve
```

ডেস্কটপ সংস্করণের জন্য:
```sh
cargo run --no-default-features --features desktop
```

অ্যান্ড্রয়েড APK তৈরির জন্য:
```sh
./build-apk.sh
```
